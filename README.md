# LandLord — Telegram-бот учёта аренды и коммунальных платежей

## Установка обновления
1. Остановите бота.
2. Сделайте резервную копию базы: `npm run backup` (или скопируйте `data/rental_bot.db`).
3. Замените файлы бота файлами из архива. **Папку `data/` не трогайте** — в архиве базы нет, ваша база остаётся как есть.
4. Удалите старый файл `schema.js` в корне проекта (он был дублем `src/schema.js`).
5. `npm install` и `npm start`.

Структура базы данных не менялась: новые таблицы и колонки не добавлялись, все старые данные работают.

## Меню администратора
- 💰 Платёж — внести платёж
- 📥 Показания — ввести показания счётчиков
- 📜 История — история по 10 записей, листание ◀️ ▶️, удаление платежей 🗑
- 🏠 Квартиры — список и выбор квартиры
- ⚙️ Тарифы — подменю изменения тарифов
- 🏷 Аренда — настройки аренды
- ❌ Отмена — выход из любого диалога (также /cancel)

## Как внести платёж (админ и суперадмин)
1. Нажмите «💰 Платёж».
2. Введите сумму:
   - **положительная** (например `5000`) — платёж получен, долг уменьшится;
   - **отрицательная** (например `-5000`) — долг арендатора увеличится на 5000.
   Ноль не принимается. Можно писать с пробелами и запятой: `-5 000,50`.
3. Бот покажет баланс «Сейчас» и «После». Нажмите «✅ Сохранить» или «❌ Отмена».
4. Арендатор получит уведомление.

## Как удалить платёж
1. «📜 История» → нажмите 🗑 с номером нужной записи.
2. Подтвердите «🗑 Да, удалить».
3. Баланс пересчитается, арендатор получит уведомление в чате.

Удалять можно только платежи и корректировки (не начисления) и только по своим квартирам — это касается и суперадмина.
