# Отчёт о проверке кода

## Исправленные ошибки
1. **Баланс мог разойтись с историей.** Запись операции и изменение баланса выполнялись отдельно; при сбое между ними данные расходились. Теперь начисления, платежи, начальный баланс и удаления выполняются одной транзакцией базы.
2. **Накопление ошибок округления.** Баланс теперь округляется до копеек при каждом изменении.
3. **Повторное удаление начисления** (`deleteAccrual`) возвращало на баланс только одно начисление месяца, если их было несколько. Теперь учитываются все.
4. **«100 коп.»** — `formatMoney` мог показывать, например, «1234 руб. 100 коп.». Исправлено.
5. **Сообщение о пробном периоде** показывало символы `\n` вместо переносов строк.
6. **«руб. руб.»** в уведомлении арендатору о платеже.
7. **Даты в истории** читались как местное время, хотя база хранит UTC — дата могла сдвигаться. Теперь показывается по часовому поясу бота.
8. **Ошибка запуска** не обрабатывалась — бот мог висеть без сообщения. Добавлены обработчики ошибок запуска и необработанных исключений; в лог пишется полный стек.
9. **Неверная сумма платежа** сбрасывала весь диалог — теперь бот просит ввести сумму ещё раз.
10. Удалён дубль `schema.js` в корне проекта.

## Новое
- Отрицательная сумма платежа (админ и суперадмин) — увеличивает долг, с подтверждением.
- Удаление платежей из истории (только своих квартир), с уведомлением арендатору.
- Экран подтверждения платежа с балансом «до/после».
- Компактное меню, подменю тарифов, кнопка «❌ Отмена» во всех диалогах, история по страницам.
- Старые кнопки (если у пользователя закэширована старая клавиатура) продолжают работать.

## Замечания (не менялось)
- Состояние диалогов хранится в памяти: при перезапуске бота незавершённые диалоги сбрасываются.
- Контакт поддержки `@Cheatgtp` зашит в тексты во многих местах — удобнее вынести в `.env`.
- Структура базы не менялась по вашему требованию.
